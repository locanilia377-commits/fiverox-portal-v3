## Кликабельный MVP по ТЗ

[Карта процессов](https://locanilia377-commits.github.io/fiverox-portal-v3/#/mvp-processes) открывает сценарии с нужной ролью. Роли можно менять через личный кабинет. В операционном кабинете есть демочасы для проверки сроков и истечения резерва.

Записи и переходы работают на демонстрационных данных в браузере. Интеграции, внешняя оплата, подпись, доставка сообщений и файловый обмен показаны моделями. Значения по открытым условиям ТЗ приведены как демонстрационные параметры.
